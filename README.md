# Сайт Николая Бандурченко

[Открыть сайт](https://aurin2012.github.io/bandurchenko/)

Статический сайт: три карточки социальных сетей, две книги и видеокурс. Аннотации, оплата и отзывы открываются в отдельных окнах.

- `index.html` — содержание главной страницы и аннотации.
- `social.css` — оформление и адаптивная вёрстка.
- `social.js` — открытие и закрытие аннотаций.
- `annotations.html` — аннотации для браузеров без JavaScript.
- `assets/fact-dark.png`, `assets/cover-2.jpg`, `assets/cover-3.jpg` — изображения товаров.
- `offer.html` — проект условий покупки. Пока помечен как проект и требует утверждения перед введением в действие.

Платёжные ссылки ЮMoney сохранены с исходного сайта. Способ оплаты выбирается на стороне ЮMoney.

GitHub Pages публикует статические файлы из корня репозитория. Файл `.nojekyll` отключает обработку старой темы Jekyll. Источники и лицензии значков указаны в `assets/SOCIAL-ICONS-LICENSE.txt`.

Предыдущая версия доступна в истории Git.
